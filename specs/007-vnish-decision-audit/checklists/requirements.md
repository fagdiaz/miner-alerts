# Requirements Quality Checklist

- [x] Scope is observational and explicitly excludes policy changes.
- [x] Real Vnish fields and multi-entry STATS behavior are documented.
- [x] Electrical-voltage limitations are explicit.
- [x] Migration preservation and retention are measurable.
- [x] Every relevant auto-reboot result is enumerated.
- [x] Telegram commands are read-only and deterministic.
- [x] No new dependency, service, dashboard, or container is required.
- [x] Windows validation and deferred service restart are explicit.
- [x] Secrets and raw payload storage are prohibited.
- [x] Success criteria are testable.
