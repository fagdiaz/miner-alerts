# Requirements Quality Checklist

- [x] Tail semantics are explicit and measurable.
- [x] Timestamp uncertainty and provenance are explicit.
- [x] Schema migration preserves prior versions.
- [x] Scheduling is isolated and non-overlapping.
- [x] Collector health excludes raw data.
- [x] Diagnose is SQLite-only and bounded.
- [x] No action-policy coupling is allowed.
- [x] Failure and stale-data behavior are explicit.
- [x] Windows validation is included.
- [x] Real config/state remain protected.
- [x] Runtime rollout is a separate final gate.
