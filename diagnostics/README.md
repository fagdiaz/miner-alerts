# Directorio de Diagnósticos y Métricas en Runtime

Este directorio está reservado exclusivamente para la generación de reportes transitorios, snapshots de métricas y capturas de diagnóstico en tiempo real generadas por `miner_monitor.py` y las herramientas de diagnóstico local (`tools/miner_diagnostics.py`).

Los diagnósticos históricos previos de julio y agosto de 2026 han sido centralizados y archivados en [`docs/archive/historical_diagnostics/`](../docs/archive/historical_diagnostics/).
