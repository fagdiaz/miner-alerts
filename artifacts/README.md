# Directorio de Artefactos de Sesión

Este directorio está destinado exclusivamente para la generación transitoria de artefactos, reportes y salidas temporales de trabajo emitidas durante las sesiones operativas y de desarrollo.

Los artefactos históricos de pruebas de recuperación y fases previas han sido consolidados y archivados en [`docs/archive/historical_artifacts/`](../docs/archive/historical_artifacts/).
