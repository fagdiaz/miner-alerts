HALLAZGO PREVIO ESENCIAL:
En T006 se implementó la lectura de configuración `AcquisitionConfig.from_mapping(config)` en `app/miner_monitor.py:3690`, pero el bucle de sondeo de la flota en `while True:` (líneas 3829-3845) aún ejecuta exclusivamente el sondeo secuencial sincrónico (`read_summary` + `read_stats_snapshot`). Para activar la adquisición adaptativa en producción, se requiere cablear `BoundedAcquirer` en el loop principal preservando al 100% el fallback secuencial.

PASO 1: Cablear `BoundedAcquirer` en `app/miner_monitor.py`
------------------------------------------------------------
1. Importaciones en `app/miner_monitor.py`:
   - Importar `BoundedAcquirer`, `MinerEndpoint`, `AcquisitionEpoch`, `Api4028Transport` desde `.acquisition` / `acquisition`.
2. Inicialización de Acquirer y Endpoints (antes de iniciar el bucle `while True:`, ej. tras validar `valid_miners`):
   - Construir la tupla de endpoints con la misma clave de estado:
     `acq_endpoints = tuple(MinerEndpoint(key=f"{m['name']}|{m['host']}:{m['port']}", host=m['host'], port=m['port']) for m in valid_miners)`
   - Si `acq_config.enabled`:
     instanciar `acquirer = BoundedAcquirer(Api4028Transport(), workers=acq_config.workers, timeout_seconds=acq_config.timeout_seconds)`
   - Asegurar cierre limpio en `finally:` o salida del proceso: `if acquirer: acquirer.close()`.
3. Ejecución en el bucle principal `while True:`:
   - Al inicio del tick (antes de `for miner in valid_miners:`):
     ```python
     envelopes: Optional[Dict[str, MinerSampleEnvelope]] = None
     if acq_config.enabled and acquirer is not None:
         epoch = AcquisitionEpoch(
             epoch_id=tick_sequence,
             scheduled_monotonic=tick_start,
             deadline_monotonic=tick_start + acq_config.deadline_seconds,
             observed_ts=now_ts,
         )
         try:
             envelopes = acquirer.collect_authoritative(acq_endpoints, epoch)
         except Exception as exc:
             log(f"[WARN] Error en adquisición adaptativa: {exc}. Usando fallback secuencial.")
             envelopes = None
     ```
   - Dentro de `for miner in valid_miners:` (sustituyendo o complementando líneas 3839-3843):
     ```python
     if envelopes is not None and state_key in envelopes:
         env = envelopes[state_key]
         rate_ths = env.rate_ths
         elapsed = env.elapsed_seconds
         responded = env.responded
         summary_entry = env.summary_entry
         active_boards = env.active_boards
         stats_response = env.stats_response
     else:
         rate_ths, elapsed, responded, summary_entry = read_summary(host, port)
         active_boards = None
         stats_response = None
         if responded:
             active_boards, _, stats_response = read_stats_snapshot(host, port)
     ```
   - El resto de la lógica de evaluación (QA force, streaks, estados, auto-reboot, watchdog) permanece **100% INTACTO**.
